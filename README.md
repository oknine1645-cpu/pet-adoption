# 🐾 บ้านพักใจ – ระบบจัดการและรับเลี้ยงสัตว์เลี้ยง (Pet Adoption System)

เว็บแอปพลิเคชันสำหรับศูนย์พักพิงสัตว์เลี้ยง เพื่อประชาสัมพันธ์สัตว์ที่กำลังหาบ้านใหม่ จัดการสถานะการรับเลี้ยง และอำนวยความสะดวกให้เจ้าหน้าที่ผ่านระบบหลังบ้านที่ปลอดภัย

---

## 🛠️ เทคโนโลยีที่ใช้งาน (Tech Stack)

- **Frontend & Backend**: Next.js (App Router), React 19
- **Database & ORM**: PostgreSQL พร้อม Prisma ORM
- **Authentication**: NextAuth.js (Auth.js) พร้อม Google OAuth Provider และระบบตรวจสอบสิทธิ์ Admin Role
- **Storage**: Cloudinary สำหรับจัดเก็บไฟล์รูปภาพสัตว์เลี้ยง
- **Styling & Fonts**: CSS Modules / Next Font (`Prompt`)

---

## ✨ ฟีเจอร์หลัก (Key Features)

### ฝั่งผู้ใช้งานทั่วไป (Public)
- 🐶 **ค้นหาและกรองสัตว์เลี้ยง**: กรองตามประเภท (สุนัข/แมว), กรองเพศ, ค้นหาตามชื่อ/สายพันธุ์, และจัดเรียงตามวันที่หรืออายุ
- 👶 **ป้ายเตือนอายุลูกสัตว์**: แจ้งเตือนสัตว์ที่มีอายุน้อยกว่า 2 เดือนว่ายังไม่พร้อมแยกจากแม่
- ❤️ **ระบบบันทึกรายการโปรด (Favorites)**: บันทึกสัตว์เลี้ยงที่สนใจผ่าน Local Storage
- 🌐 **รองรับ 2 ภาษา**: สามารถสลับใช้งานภาษาไทยและภาษาอังกฤษได้ทั้งระบบ
- 📱 **Responsive Design**: แสดงผลสวยงาม รองรับทั้งมือถือและคอมพิวเตอร์

### ฝั่งเจ้าหน้าที่ (Admin Only)
- 🔐 **ระบบความปลอดภัยเข้มงวด**: ล็อกอินผ่าน Google OAuth และจำกัดสิทธิ์เฉพาะบัญชีที่มี Role เป็น `ADMIN`
- ➕ **เพิ่ม/แก้ไขข้อมูลสัตว์เลี้ยง**: ฟอร์มบันทึกข้อมูลพร้อมระบบอัปโหลดรูปภาพเข้า Cloudinary อัตโนมัติ
- 📋 **จัดการสถานะ**: เปลี่ยนสถานะได้ระหว่าง `AVAILABLE` (พร้อมรับเลี้ยง), `PENDING` (รอพิจารณา), `ADOPTED` (รับเลี้ยงแล้ว) และ `UNAVAILABLE` (ปิดรับเลี้ยงชั่วคราว)
- 🗑️ **ลบข้อมูลอย่างปลอดภัย**: มีกล่องยืนยัน (Confirm Modal) พร้อมคีย์ลัด Esc เพื่อป้องกันการกดลบโดยไม่ตั้งใจ
